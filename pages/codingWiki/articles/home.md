## Compilers and Interpreters
Compilers and Interpreters is the software that converts the written code into computer instructions, We currently write code within a readable format that which then goes through software that converts readable text into instructions the CPU can understand depending on the technology used this can be done during runtime and or converted to a executable code thats directly computer instructions.

Compilers convert written code directly into machine code.
[Compilers](#compilersAndInterpreters/compilers)

Interpreters convert the written code to machine code using a translation layer.
[Interpreters](#compilersAndInterpreters/interpreters)
