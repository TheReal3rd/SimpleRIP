C Web IDE — Available Packages

C IDE  ·  Samples  ·  Simple.rip

This IDE runs C-style programs in the browser with JSCPP (an interpreter). Prefer the C headers (<stdio.h>) or their C++ wrappers (<cstdio>) — both resolve to the same libraries.

IDE extensions added by this project

JSCPP’s stock stdlib / string libraries do not ship malloc or byte-memory helpers. This IDE patches those headers at runtime so malloc, calloc, realloc, free, memcpy, memmove, memset, and memcmp work for teaching samples. See memory.c.

Headers you can #include

HeaderAliasPurpose
<cstdio><stdio.h>Formatted I/O
<cstdlib><stdlib.h>Conversions, rand, heap (extended)
<cstring><string.h>C strings + memory ops (extended)
<cctype><ctype.h>Character tests / case
<cmath><math.h>Floating-point math
<ctime><time.h>time() only
<stddef.h>—size_t, ptrdiff_t, … extended
<stdint.h>—int8_t…uint64_t extended
<stdbool.h>—bool, true/false extended
<iostream>—C++ cin / cout / endl
<iomanip>—setw, setprecision, setfill

Emulated typedefs (always available)

These are registered automatically (no include required), and also via the headers above: size_t, ssize_t, ptrdiff_t, intptr_t, uintptr_t, int8_t/uint8_t, int16_t/uint16_t, int32_t/uint32_t, int64_t/uint64_t, _Bool, time_t, clock_t, off_t, plus helpers uint/ulong/byte. They map onto JSCPP’s integer model (typically 32-bit int/unsigned).

<iostream> + <iomanip>

Language features

Supported (most programs)
  • Types: char, int, long, float, double, unsigned variants, bool, pointers, arrays
  • Control: if/else, switch, for, while, do/while
  • Functions, recursion, typedef, sizeof (not sizeof(void*))
  • Preprocessor: #include, #define (simple macros)
  • IDE heap: malloc/calloc/realloc/free + patched strcpy/strcat/... + memcpy family
  • IDE structs: struct / typedef struct, member access ., pointers & / ->
Known JSCPP limits (do not use)
  • sprintf — crashes in this runtime
  • %ld / length modifiers — use %d with a cast
  • (int *)malloc(...) pointer casts — use char *
  • if (p) / p == NULL on pointers — unreliable
  • #if EXPR / #else — unreliable; prefer plain #define
  • <math.h> together with <stdlib.h> — abs overload clash
  • Struct brace-init (Point p = {1,2}), bitfields, and flexible members — not supported
  • No real files/threads/networking; educational subset only

Verify samples with node tools/run_c_tests.js (includes selftest.c).
